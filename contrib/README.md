# Contrib

This folder contains archived previous experiments, prototypes, and reference materials related to the FastConv project. These materials are preserved for consultation, study, or reuse but are not part of the main synthesizable or simulation flow.

Notable legacy blocks under `rtl/`: the `System` wrappers of the previous architecture (`rtl/system/`,
`rtl/system-bus/`, moved here on 2026-11-18) with their controllers (`rtl/control-sum/`, `rtl/control-bus/`) and
engine (`rtl/conv-mux/`). The `synthesis/sys-*` campaigns were run with them. Current cores live in `../rtl/conv*/`. Use these resources to gain insight into earlier design ideas or supplementary techniques explored during development.
